# 工地小掌柜 · 工地管理微信小程序

面向 **家装 / 整装公司** 的内部经营管理小程序，覆盖「获客 → 报价 → 签约 → 施工 → 采购 → 收款 → 售后 → 经营分析」全流程。

- **技术栈**：微信原生小程序（WXML + WXSS + JS），**零 npm、零构建**
- **运行方式**：微信开发者工具直接导入即可运行
- **架构**：多租户团队模型（老板创建团队 → 员工凭邀请码加入 → 数据按团队隔离共享）
- **规模**：29 个页面、6 个共享组件（实际在用 5 个）、14 个业务模块

## 一.5、常见问题

### 编译报错：`game.json: 未找到 game.json 文件`

**原因**：导入项目时「项目类型」选成了 **小游戏**，开发者工具就去小游戏包里找 `game.json`。
本项目是 **小程序**，入口文件是 `app.json`。

**解决**：

1. 在开发者工具里 **关闭当前项目窗口**（项目列表右键 → 移除，或「文件 → 关闭项目」）
2. 回到开发者工具首页 → **导入项目**
3. 目录选 `zhuangxiu-erp`
4. **项目类型下拉选「小程序」**（不要选「小游戏」）
5. AppID 选「**测试号**」
6. 确定

> 判断依据：本项目根目录有 `app.json` / `app.wxss`，没有 `game.json`，是标准小程序工程。

### 页面全白 / 只有导航栏

**原因**：项目仍被开发者工具按「小游戏」运行时加载（日志中会出现 `gamePage.html`、`gameAppConfig`）。
即项目记录里被标记成了小游戏，此时改 `project.config.json` 无效。

**解决**：

1. **完全退出**微信开发者工具（菜单「微信开发者工具 → 退出」，不是只关窗口）
2. 重新打开，在首页项目列表里 **删除** `zhuangxiu-erp` 这条记录
3. 点「导入项目」，目录选 `zhuangxiu-erp`，**项目类型选「小程序」**，AppID 选「测试号」
4. 菜单「工具 → 清除缓存 → 清除全部缓存」，再点「编译」

### 其他常见问题

| 现象 | 处理 |
|---|---|
| 提示 AppID 不合法 | AppID 直接选「测试号」，或填自己的小程序 AppID |
| 页面空白 / 无数据 | 菜单「工具 → 清除缓存 → 清除全部缓存」，然后重新编译 |
| 数据想恢复初始状态 | 页面「我的 → 重置演示数据」，或删掉缓存后重新编译 |
| 真机预览白屏 | 需要先 `npm test` 无报错；真机预览要求 AppID 是自己的正式小程序 AppID |

## 二、功能模块

### 🏢 团队机制（多租户）

支持**一个老板 + 多个员工**共用同一套数据：

- **老板**：创建团队后自动成为老板，获得 6 位邀请码
- **员工**：登录后输入邀请码加入，与同事看到同一批客户、跟进记录和工地
- **数据隔离**：业务数据都带 `teamId`，不同团队互相看不到
- **角色权限**（老板可在团队页调整）：

| 角色 | 可访问模块 |
|---|---|
| 老板 | 全部 |
| 设计师 / 销售 | 客户、报价、合同、项目、售后 |
| 项目经理 | 项目、材料、售后、客户 |
| 财务 | 财务、报表、合同、客户、项目 |

- 老板可改团队名、重置邀请码、调整成员角色、移除成员
- 客户列表显示**负责人**，并支持按同事筛选


### 📊 工作台（首页）
- 核心指标：在建工地、本月回款、待收款项、平均进度

- 待我处理：聚合 6 类审批待办
- 九宫格快捷入口
- 在建工地卡片：当前阶段、进度条、剩余工期、项目经理

### 👥 客户 CRM
- 客户列表：状态筛选 + 搜索（姓名/电话/小区）、意向等级 A/B/C/D、下次跟进提醒

### 📐 报价预算

### 🏗 项目工地

- **项目详情**：进度、财务（合同/已收/已支出/毛利/回款率/成本率）、九宫格功能入口、节点预览、变更签证、巡检、项目团队

## 四、数据层说明

演示版用 `wx.setStorageSync` 模拟后端，**所有页面只通过 `data/store.js` 读写数据**。

### 团队隔离怎么实现的

- 所有业务记录都带 `teamId`，`store.list(name)` 内部按当前登录账号的团队自动过滤
- `store.insert()` 自动给新记录打上当前团队标记，页面无需关心
- 未登录时 `list()` 返回空数组，避免登录前看到任何数据
- 团队相关的读操作走 `store.listAll()`（不做过滤，仅登录页/团队页使用）
- **接入真实后端时**：把 `list()/insert()/update()` 内部换成 `wx.request` 或云开发数据库查询，把团队过滤交给后端做（`where teamId == 当前团队`），页面代码不用动

### 已实现的数据集合

| 集合 | 说明 |
|---|---|
| `teams` | 团队（公司名、老板、邀请码、行业、城市） |
| `users` | 员工 / 团队成员（含角色、`teamId`） |
| `customers` | 客户线索 |
| `follows` | 跟进记录 |
| `quotes` | 报价单（含明细 items） |
| `contracts` | 合同（含分期 payPlan） |
| `projects` | 项目（含施工节点 nodes） |
| `inspections` | 巡检记录（含检查项） |
| `changes` | 变更签证 |
| `receipts` | 收款流水 |
| `expenses` | 支出流水 |
| `materials` | 材料采购 |
| `aftersales` | 售后工单（含处理记录） |
| `todos` | 待办审批 |

### 内置的业务联动

- 登记收款 → 自动更新合同分期状态、项目已收款
- 审批支出通过 → 自动累加到项目成本
- **报价转合同 → 自动开立施工项目 + 生成 11 个标准工序节点 → 客户状态推进为「已签约」**
- 节点完成 → 自动重算进度；全部完成 → 项目自动转「已完工」
- 首个节点开工 → 项目自动从「未开工」转「施工中」
- 变更签证确认 → 状态流转并留痕
- 626 行的种子数据基于「今天」动态计算日期，**任何时候打开都有进行中工地和逾期提醒**

### 接入真实后端（团队共享必须走这一步）

本地存储只能存在一台手机上，**跨设备/多人共享必须接后端**。推荐微信云开发：

1. 注册小程序 AppID，替换 `project.config.json` 里的 `appid`
2. 开通「云开发」，创建 14 个集合（`teams / users / customers / ...`），权限设为「仅创建者可读写」或自定义
3. 在 `data/store.js` 里把读写替换成 `wx.cloud.database()`，团队过滤交给查询条件：

```js
// 改造前（本地）
function list(name) {
  return load()[name].filter((x) => x.teamId === currentTeamId());
}

// 改造后（云开发）
async function list(name) {
  const db = wx.cloud.database();
  const res = await db.collection(name)
    .where({ teamId: currentTeamId() })
    .limit(100)
    .get();
  return res.data;
}
```

页面层代码无需改动。建议同时给集合加 `teamId` 索引，并在云函数里做权限校验。
